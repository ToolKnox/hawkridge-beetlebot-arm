# Bill of Material

Parts list for the Hawkridge package. The visible PDF version is attached in the Printables Documentation section: https://www.printables.com/model/1776625-beetlebot-arm

| Item | Qty | Category | Notes |
|---|---:|---|---|
| Arduino Mega compatible board | 1 | Electronics | Upstream README recommends Arduino Mega/Uno, preferably Mega. |
| MG996R continuous rotation servo | 2 | Actuators | README specifies two MG996R servos for base and end-effector bracket. |
| MG995 high torque servo | 2 | Actuators | README specifies two MG995 servos for both arm joints. |
| SG90 9g micro servo | 2 | Actuators | README specifies two SG90 servos for the gripper attachment. |
| OV7670 camera module | 1 | Vision | README lists an OV7670 camera module. |
| LM2596 DC-DC step-down buck converter | 1 | Power | README lists a DC-to-DC step-down buck converter, LM2596. |
| PCA9685 16-channel 12-bit servo driver board | 1 | Electronics | README lists the PCA9685 16-channel 12-bit servo driver board. |
| 12V DC power supply | 1 | Power | README lists a 12V DC power source for the servo system. |
| 608ZZ 8x22x7 mm ball bearing | 2 | Hardware | README specifies two 8x22x7 mm ball bearings. |
| M3 screw and nut assortment | 1 | Hardware | README lists screws and nuts; M3 assortment covers the small robotic-arm fasteners users commonly need. |
| Dupont jumper wire kit | 1 | Wiring | README lists jumper cables for Arduino/PCA9685/sensor wiring. |
